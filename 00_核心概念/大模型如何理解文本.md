# 大模型如何"理解"文本？——从"分析文章主题"切入

> 从 token、上下文表示、注意力和训练目标解释摘要能力，区分已知机制、行为证据与教学类比。
>
> **审校范围：2026-09-30 修订机制解释并补来源，未运行模型或 probing 实验。** 讨论典型 Transformer，不推断未公开模型的内部配置。

---

## 一句话回答

大模型把文本转换成向量序列，经过多层上下文交互和非线性变换，生成后续 token 的概率分布。训练使它能在许多任务上归纳信息、生成摘要。**不能只用“找主题词”“查相似答案”或“全文压成一个向量”解释这套能力。**

---

## 引子：什么叫"理解一篇文章的主题"？

人类做这件事时大致经历：读句子 → 抓关键词 → 找重复出现的概念 → 推断作者意图 → 一句话总结。

模型能表现出某些归纳能力，但是否具有与人类相同的理解或意识，不能由一段流畅回答确定。下面区分可解释的计算机制与需要实验检验的行为，而不是把人类的阅读步骤逐一套到模型上。

---

## 第一层：文字先变成"几何对象"

文本先经 tokenizer 转换成 token ID；token 可以是子词、字节、标点或词等，不一定介于一个汉字与一个词之间。输入 embedding 把 ID 映射成向量，再结合位置信息进入网络。向量维度取决于模型配置。

> 词嵌入的具体在网络结构里的位置，参见 [Transformer.md § 关键组件](Transformer.md#关键组件)。本节聚焦它的**语义几何特性**——这是它能用于"理解"的根本原因。

### 关键事实：向量空间是有"语义几何"的

训练完成后，词向量在空间里的位置不是随机的，而是反映了语义关系。最经典的例子：

```
某些词向量模型中的经典近似示例，并非任意模型都成立：
    国王 − 男人 + 女人 ≈ 王后
    巴黎 − 法国 + 日本 ≈ 东京
```

这些示例说明某些关系可以表现为向量方向，但并非任意模型、词和层都具有相同性质。

### 这意味着什么？

整篇文章变成一串向量序列，但词之间距离近不等于文章主题就已确定。否定、反讽和关系结构会改变含义。

要区分**输入 embedding**（初始 token 表示）、**上下文表示**（结合当前文本经多层计算后的表示），以及用于检索的**整段文本 embedding**（某些模型或池化方案的定长输出）。后者不是所有生成模型必须经过的步骤。

---

## 第二层：注意力机制按上下文聚合信息

> attention 的 Q/K/V 数学原理与多头机制，见 [注意力机制.md](注意力机制.md)。本节聚焦它如何对应到"主题抽取"任务。

### 权重、可见位置与主题重要性不是一回事

self-attention 根据 query/key 匹配分数、掩码和归一化来聚合 value。双向编码器通常可关注所有未屏蔽输入位置；自回归 decoder 的因果注意力只能关注自身与更早位置，不能看未来。padding、局部窗口等也可能限制可见位置。

下面是**手工教学示例，不是模型实测**：一个头在因果掩码与 softmax 后、dropout 前的权重。

```
query / key   token1   token2   token3
token1         1.0      0.0      0.0
token2         0.4      0.6      0.0
token3         0.2      0.3      0.5
```

每行和为 1，未来位置为 0。这说明归一化与可见性，**不说明某个 token 是全文主题**。输出还受 value、输出投影、前馈网络、残差路径和其他层影响，不能把 attention 热图直接当成完整的因果解释。

### 多头让不同"专家"看不同角度

multi-head attention（多头注意力）让多个"头"并行工作：

- 一个头可能专门捕捉**指代关系**（"他" 指谁）
- 某些头可能呈现**句法或位置模式**
- 不同头的模式也可能重叠、变化，不能预先规定固定分工

“多个专家”只是教学类比，不是每个头都有可命名职责的架构保证。注意力能否作为解释需要诊断；相关研究及争论见文末来源。

## 第三层：层级抽象——词 → 短语 → 主题

不同模型的层数与表示分布不同。不能用未公开模型的猜测层数，为“固定层级分工”背书。

### probing（探针实验）告诉我们的事

**Probing** 是测试某层表示中能否解码出词性、句法等信息的方法。结果随模型、任务、探针设计而变，不能固定成“低层只处理语法，高层只处理主题”。探针能读出某信息，也不自动证明模型在原任务中使用了它；因果作用需要干预、消融等额外证据。

### 层间更新的通常仍是一串表示

典型 Transformer 每层通常保留“序列长度 × 隐藏维度”的表示，通过注意力、前馈网络和残差进行更新。它不必把全文压缩成一个独立向量再生成全文摘要。

```
原始文章（几千 token）
       ↓ token 化、输入表示与位置信息
       ↓ 多层注意力、前馈网络与残差更新
   每个位置的上下文表示
       ↓ 用相应位置的表示预测下一个 token
   接入新 token，继续生成总结
```

一次下一 token 预测使用相应位置的向量，不意味着后续生成丢弃前文。模型仍可通过注意力访问历史信息；常见实现用 KV Cache 保存历史 key/value，减少重复计算。

## 第四层：训练让它学习语言与任务模式

> 预训练与 SFT、RLHF 等后训练阶段的区别，见 [模型训练技术速查.md](模型训练技术速查.md)。这些阶段不能统称为预训练。

### 训练语料里天然包含"输入-总结"配对

互联网语言材料中可能存在“长内容 + 短总结”的结构，例如：

| 长内容 | 配对的"总结" |
|--------|------------|
| 论文正文 | abstract（摘要） |
| 新闻报道 | 标题、导语 |
| 长文章 | TL;DR（懒人版总结） |
| 维基百科条目 | 第一段定义 |
| 知乎长答案 | 评论里"总结一下就是…" |
| 视频字幕 | 视频标题 |

这些是语料可能包含的结构，不是对某个模型训练集的统计。没有数据披露时，不能断言它见过“亿万篇文章—摘要对”。预训练与指令微调、偏好优化等后训练都可能影响摘要表现。

### 你让它"分析主题"时，它在做什么？

模型基于当前文章、任务指令和已生成内容预测后续 token，不是显式遍历训练文章找答案。概率建模是输出机制，不能由此直接否定一切推理行为；泛化、记忆、归纳是否可靠，需要任务实验来判断。

---

## 检验“理解”：它能否应对新例子？

与其凭措辞判断“懂不懂”，不如检验：改成否定后结论会不会改变？换人名后逻辑能否保持？加入高频干扰词后是否仍忠于原文？摘要中的每条主张是否有证据？这些是可测的行为问题，不是意识判定。

### 实验证据：上下文位置会影响"理解"质量

**Lost in the Middle** 在多文档问答、键值检索等实验中发现，相关信息位置会影响受测模型表现，中段在一些设置下较差。这是指定任务和模型下的行为证据，不是所有模型、所有文章的定律。

> 详见 [02_提示词工程/01_AI对话的底层逻辑.md § 1.7](../02_提示词工程/01_AI对话的底层逻辑.md) 中关于 Lost in the Middle 的展开。

这个现象不能单独证明“不理解”，也不能据此确定原因就是“训练时中段不受强调”。应用中应测试实际模型的信息利用率，而不是只看上下文窗口长度。

## 这套机制的局限

LLM 的"主题分析"在以下场景容易翻车：

| 场景 | 为什么会翻车 |
|------|-----------|
| **超长文档** | 上下文窗口溢出 / 中段遗失 |
| **跨文档推理** | 可能未正确对齐实体、时间和冲突信息 |
| **新概念主题** | 背景不足或把熟悉模式误套到新问题 |
| **反讽 / 暗喻** | 字面词与真实主题相反，模型会被表面词义带偏 |
| **作者隐含立场** | 可能把缺乏依据的猜测写成事实 |

读者通常不知道训练数据中见过多少类似样本，因此应按任务测试、证据一致性和失败案例判断可信度。

## 一个粗暴的类比

可以把训练类比为“接触大量语言材料后形成可迁移的规律”，但这不说明模型像人一样读书，也不提供训练数据量、参数量或 GPU 数量的证据。

### 自测与迁移

- 不看原文，区分输入 embedding、上下文表示和整段文本 embedding。
- 检查上面示例每行之和；解释 softmax 前分数为什么不要求和为 1。
- 为三篇短文构造否定、干扰词、证据换位置版本，记录模型与提示配置，核对摘要。
- 为一次错误找原文证据；不要仅凭输出错误断言某个 attention 头“坏了”。

这些是待执行的学习任务，不是本文已经完成的实验。

## 术语速查

| 术语 | 中文 | 含义 |
|------|------|------|
| **token** | 词元 | tokenizer 使用的处理单位，可能是子词、字节、标点等 |
| **embedding** | 嵌入 | 将离散 ID 等输入映射成向量；维度取决于配置 |
| **self-attention** | 自注意力 | 在掩码允许的位置间计算权重、聚合 value |
| **multi-head attention** | 多头注意力 | 多个注意力并行工作，每个头关注不同角度 |
| **probing** | 探针实验 | 在中间层接小分类器，测试该层学到了什么 |
| **pretraining** | 预训练 | 在万亿级无标注语料上学"下一个词预测" |
| **Lost in the Middle** | 中段遗失 | 长上下文里中段信息被"忽视"的现象 |
| **conditional probability** | 条件概率 | 给定上下文的输出分布；单凭它不能判断推理行为是否发生 |
