# 00 核心概念

本模块收录 AI / 大模型的**底层原理**：文本怎么变成模型能算的东西、注意力机制怎么工作、模型是怎么练出来的、上下文窗口和计费的边界在哪。它是全知识库的地基——其他模块（应用实践、Agent 工程）遇到"为什么会这样"的问题时，答案通常在这里。

## 推荐阅读顺序

1. [上下文窗口与Token计费.md](上下文窗口与Token计费.md)：先建立"模型一次能看见多少"的直觉，这是后面所有内容的物理边界。
2. [Transformer.md](Transformer.md)：所有主流 LLM 的核心架构。
3. [注意力机制.md](注意力机制.md)：Transformer 的灵魂，理解模型如何"关注重点"。
4. [大模型如何理解文本.md](大模型如何理解文本.md)：把"理解"这件事拆到底层机制，揭穿拟人化幻觉。
5. [模型训练技术速查.md](模型训练技术速查.md)：预训练 → SFT → RLHF/DPO 的完整流水线。
6. [Dense与MoE架构对比.md](Dense与MoE架构对比.md)：进入架构选型层，理解 2026 年主流模型的两条路线。
