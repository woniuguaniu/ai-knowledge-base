> 一句话定位：沿着“查搭配 → 学表示 → 带记忆 → 会取舍 → 按需回看”的学习路线，理解语言模型为什么一步步走向 Transformer。

> 前置知识：知道“概率”表示可能性即可，不要求编程或高等数学。阅读后应能：用自己的话解释每一步解决了什么问题，并区分 Embedding、模型架构和训练方法。

## 0. 先看全景

### 共同问题：接下来最可能出现什么？

给出半句话：

```text
我 想 喝 ____
```

“茶”“水”“咖啡”都可能接上去。语言模型可以给不同候选分配概率，再据此生成后续内容。

**这里的主线，是估计“给定前文，下一个单位出现的概率”的方法如何发展。** 为了好懂，前面把单位简称为“词”；实际模型也可能按字、子词或字节等 token 工作。并非所有语言模型都采用下一 token 预测这一种训练目标。

### 一张学习路线图

```text
N-gram：统计局部词语搭配出现了多少次
    ↓ 不只记搭配，还希望相近的词能共享规律
神经语言模型：Embedding + 神经网络
    ↓ 不满足于固定几个前文词，希望利用更早的历史
RNN：用递推的状态携带历史
    ↓ 历史容易被冲淡，希望学会保留与更新
LSTM：在循环网络里加入可学习的记忆控制
    ↓ 不想把所有细节都挤进固定大小的总结
Seq2Seq + Attention：生成时按需访问输入各位置的信息
    ↓ 希望减少循环带来的顺序计算，让训练更易并行
Transformer：以注意力组织位置间的信息交互
```

**这是一条“问题如何被逐步处理”的教学路线，不是严格的发明时间顺序，也不是互斥的模型分类。** 先记住三个关系：

- **Embedding 是表示技术**：回答“词怎么变成模型能计算的东西”。RNN、LSTM、Transformer 都可以使用它。
- **LSTM 属于 RNN 家族**：它不是一种与循环网络完全无关的模型。
- **Attention 早于 Transformer**：早期注意力可以与循环网络一起使用，Transformer 把它放到了架构的中心。

## 1. N-gram：查局部搭配的次数

### 它的办法：别人经常怎么接，我就倾向于怎么接

假设一份小语料中，“喝”后面恰好出现过以下十次接续：

| 接续 | 次数 | 直接按次数估计的概率 |
|---|---|---|
| 喝 茶 | 6 | 60% |
| 喝 水 | 3 | 30% |
| 喝 咖啡 | 1 | 10% |

那么，在这个**人为构造、未做平滑**的例子里：

```text
P（茶出现在下一位｜前一个词是喝）= 6 ÷ 10 = 60%
```

竖线右侧表示条件。这里不是问“茶在所有文章里多常见”，而是问：**已经看到‘喝’，接下来出现‘茶’的可能性是多少？**

### N 到底是什么？

N-gram 指连续 N 个单位的组合。用它做下一词预测时，通常只保留前面的 N−1 个词作为条件：

| 模型 | 预测时看多长的前文 |
|---|---|
| Unigram，一元模型 | 不看前文，主要看词本身的频率 |
| Bigram，二元模型 | 看前 1 个词，例如看到“喝” |
| Trigram，三元模型 | 看前 2 个词，例如看到“想 喝” |

**类比：一本很大的“常见接话搭配表”。** 真实系统会涉及平滑、回退等处理，不只是一个裸计数表。

### 它卡在哪里？

1. **看得近**：只看最后几个词，较远的信息就用不上。
2. **表格容易变稀疏**：N 越大，可能的组合越多；很多合理搭配在训练语料里没出现过。
3. **纯计数表不显式共享语义表示**：见过“喝茶”，不代表它能像使用相近词向量的网络那样，把相关规律迁移到其他饮品。

平滑可以给没见过的组合留一点概率，回退可以改用更短的上下文；但这些办法并没有直接解决语义表示和远距离信息利用的问题。

**于是产生一个方向：能不能不为每个搭配单独记次数，而是学习词与词之间可共享的规律？**

## 2. Embedding：让词有可学习的坐标

### 先解决“词怎么交给神经网络”

计算机不能直接对“猫”这个含义做矩阵运算，需要把它表示成数字。

一种简单办法是 one-hot，也叫独热编码：

```text
猫   → [1, 0, 0]
狗   → [0, 1, 0]
汽车 → [0, 0, 1]
```

它能区分身份，却没有在这种编码的距离中体现“猫和狗比猫和汽车更接近”。

**Embedding 的做法，是给每个词或 token 一组可学习的数字。** 可以把这组数字类比为“坐标”：训练后，某些语义或用法关系能够体现在向量的距离、方向等结构里。

不过，不能把这个类比理解成“第 1 维固定代表动物，第 2 维固定代表温柔”。这些维度通常没有这样整齐的人类标签；语义相近也不是任意模型、任意词都必然距离最近。

### 这些坐标是怎么来的？

以训练一个神经语言模型为例：

```text
前文词语
   ↓ 查找对应的 Embedding
一串向量
   ↓ 神经网络计算
下一词的概率分布
   ↓ 与语料中的实际下一词比较
根据误差调整网络参数和词向量
```

反复训练后，词向量与网络一起学到有助于预测的规律。**不是先由人把全部语义写成坐标，再交给模型背诵。**

Bengio 等人 2003 年的神经概率语言模型，是“学习分布式词表示，并用网络预测后续词”的代表工作。它使用固定长度的前文，因此：**更好的表示，不等于已经解决了任意长上下文的问题。**

后来广为人知的 Word2Vec 则是一组学习词向量的方法，例如用周围词预测中心词，或用中心词预测周围词。**Word2Vec 不是“Embedding 的全部”，也不是一个拿来就能聊天的大模型。**

### 三个容易混淆的点

- **“高维”不是越高越好**：Embedding 通常是稠密向量，相比词表大小维度的 one-hot，它往往反而更低维。关键是学到了什么，不是维数大就有语义。
- **表示不等于上下文处理**：同一个“苹果”token 的初始向量通常相同；“我吃了苹果”和“苹果发布电脑”的区别，需要后续网络结合上下文处理。
- **输入词向量不等于检索向量**：把整段文档编码成一个向量用于 RAG，是另一种用途，不能与生成模型的输入 Embedding 混为一谈。

**到这里解决的是“用什么表示词”。接下来还要解决：“读到后面时，怎么带着前面的信息？”**

## 3. RNN：边读边更新一张便签

RNN 是 Recurrent Neural Network，循环神经网络。

### 它的办法：每读一个词，就更新一次状态

```text
旧便签 + 当前词的向量
          ↓ 同一套可学习的更新规则
        新便签
          ↓ 输出层
   下一词的概率分布
```

这张“便签”对应**隐藏状态**：一组随序列推进而更新的数值。不同时间步复用同一套更新参数，“循环”不是把整篇文章来回读很多遍。

相比固定只看前两个词，它可以让更早的信息通过状态一路传过来。**理论上能受到更早历史的影响，不代表实际能把所有历史完整保留下来。**

### 用一个故事看它的难处

后面几节都可以拿这段文字作对照：

> 小明把钥匙放进书包。……中间聊了很久别的事情……要开门时，他先从____

要有根据地接出“书包”，就需要利用较远处的位置信息，而不只是看到“开门”就猜常见接续。

对普通 RNN 来说，可以类比为：第一张便签记了“钥匙在书包”，之后每读一个词都要改写便签。更新很多次后，重要信息可能被冲淡。

**类比边界：隐藏状态不是中文备忘录，也不真的逐条写着事实。** 信息分布在数值中，能保留什么由结构、参数、训练和输入共同决定。

### 两个主要瓶颈

- **长距离信息难学、难保留**：训练时纠错信号要跨很多时间步传回去，可能越来越弱或越来越大，这就是梯度消失、梯度爆炸问题的一部分。
- **同一序列的状态计算有先后依赖**：后一步要等前一步的状态。不同样本和每一步内部的矩阵运算仍可并行，不能简单说“RNN 完全不能用 GPU 并行”。

**于是进一步问：能不能让状态更新更有选择，而不是让重要信息在一轮轮更新中轻易丢失？**

## 4. LSTM：给记忆加上取舍机制

LSTM 是 Long Short-Term Memory，长短期记忆网络，是 RNN 的一种改进结构。

### 它的办法：保留什么、写入什么、读出什么，分别控制

在常见的 LSTM 中，除了隐藏状态，还维护一条**细胞状态**，也常叫记忆单元状态。可以类比为：

- 普通 RNN：一张不断改写的便签。
- LSTM：有一条更方便保留信息的记录带，并设置控制信息流动的“阀门”。

| 门 | 大白话 | 实际控制的对象 |
|---|---|---|
| 遗忘门 | 旧记录留下多少？ | 旧细胞状态中各部分的保留比例 |
| 输入门 | 新信息写入多少？ | 候选新信息加入细胞状态的比例 |
| 输出门 | 这一步读出哪些内部信息？ | 细胞状态如何参与形成当前隐藏状态 |

这些门由网络学习，通常输出介于 0 和 1 之间的数值，并不是程序员逐条写好的“遇到钥匙就保存”规则。

记忆更新可以粗略理解为：

```text
当前细胞状态 = 保留下来的旧信息 + 允许写入的新信息
```

在钥匙故事里，我们希望模型学会保留与后续任务相关的信息，并减少无关内容的干扰。**这是机制可以支持的方向，不是每个训练好的 LSTM 都一定能做到的承诺。**

特别注意：**输出门不直接决定“下一词是书包还是抽屉”**。它影响隐藏状态，后面仍要通过输出层计算词的概率。

### 改进了什么，又没有解决什么？

这样的状态通路与门控设计有助于缓解普通 RNN 的长距离学习困难。但它不是无限容量的记忆仓库，长序列仍可能出错，时间步之间也仍然存在顺序依赖。

LSTM 最初发表于 1997 年；本文讲的是后来常见的三门形式，不把后续增加或完善的机制都算作原始版本的设计。

这里的“记忆”是**处理序列时维护的内部数值状态**，不是 Agent 的长期知识库，也不是模型会自动跨对话永久记住用户。

**接下来要解决的，是另一类瓶颈：即使便签更会记，能不能干脆让模型在需要时回看原文？**

## 5. Seq2Seq 与 Attention：从默写到回看

### Seq2Seq：先读一段，再写另一段

Seq2Seq 就是 Sequence to Sequence，序列到序列。它适合描述翻译这样的任务：输入一串中文，输出一串英文。

一种早期、不带注意力的编码器—解码器做法是：

```text
中文句子 → 编码器读完 → 固定大小的状态 → 解码器逐步写出英文
```

编码器负责把输入变成内部表示，解码器负责生成输出；具体可以使用 LSTM 等结构。这里的状态可能包含多层、多组向量，入门图常将其简写成“一个向量”。

**类比：读完一篇材料，只带着一张摘要卡去复述。** 输入越长、细节越多，越难把所有需要的信息都装进固定大小的摘要。

### Attention：写到哪里，就回看相关位置

注意力机制改进了这件事：**保留编码器在输入各位置产生的表示，让解码器在每一步对这些表示计算权重，再加权读取信息。**

```text
不带注意力：读原文 → 带走摘要卡 → 主要靠摘要卡写输出
带上注意力：读原文 → 保留各位置的表示 → 每一步按需要加权读取
```

“回看原文”是类比。网络实际读取的是向量表示，不是打开一个文本编辑器；它也不一定只选择一个位置，可能混合多个位置的信息。

Bahdanau 等人的代表论文在 2014 年发布预印本、2015 年发表于 ICLR，讨论了固定长度表示的瓶颈，以及如何联合学习对齐与翻译。

### 为什么还需要 Transformer？

因为**有注意力，不等于没有循环**。早期带注意力的翻译系统仍常用 RNN、LSTM 或 GRU 这样的循环结构；GRU 是另一种门控循环网络。

于是有了新的问题：**既然可以通过注意力连接远处信息，能不能不再依赖逐个位置传递的循环状态来完成主要的序列交互？**

## 6. Transformer：让注意力成为主干

2017 年的《Attention Is All You Need》提出 Transformer。原版用于序列转换，包含编码器和解码器；后来的许多生成式大模型采用以解码器为主的架构。

### 核心变化：信息不必只沿着便签逐站传递

在普通循环网络中，远处信息要经过多个时间步的状态更新；在自注意力中，**一个位置可以直接聚合掩码允许的其他位置的信息**。

“自注意力”的“自”，指查询、匹配和被聚合的信息来自同一序列的表示；不是模型拥有了自我意识。编码器—解码器之间也可以使用交叉注意力。

仍用钥匙故事作直觉对照：模型处理后面的内容时，可以在可见范围内直接利用“钥匙”“书包”等早先位置的表示，而不必只指望一条循环状态把相关信息一路传下来。

**直接可访问，不等于一定正确使用。** 注意力权重也不直接等于事实真伪、因果关系或“人类认为的重要程度”。

### Transformer 不只有注意力

一个典型的生成式 Transformer，可以简化成：

```text
文字 → token ID → 输入 Embedding + 位置信息
                        ↓
         多层注意力、前馈网络、残差与归一化
                        ↓
              相应位置的下一 token 概率
```

- **Embedding**：提供最初的 token 表示，所以它并没有被新架构淘汰。
- **位置信息**：帮助区分先后顺序，否则只知道有哪些词，还不够理解“狗咬人”和“人咬狗”的区别。
- **多头注意力**：好比用几套不同的“观察方式”看同一段信息，各自找联系，再合并结果。“投影到不同子空间”可以理解为：各个头通过各自学到的变换，把向量加工成不同的特征表示。它不保证每个头都成为分工固定的“语法专家”或“指代专家”。
- **前馈网络**：把聚合进来的信息再加工一遍。注意力让不同位置交换信息，典型前馈网络则对每个位置的向量分别做进一步变换；同一层的各个位置使用同一套加工规则。
- **残差连接**：给原来的表示留一条直接通路，把新加工的结果加回去，而不是只留下新结果。可以类比为“在旧稿上叠加修改”，这有助于信息和训练时的纠错信号流动；但不表示原始信息会被永久、原样保存。
- **归一化**：按一定规则调整一组数值的尺度，帮助训练更稳定。可以类比为给录音调节电平，让后续处理更容易进行；它不是把所有数字变成一样，也不是判断内容对不对。

这些组件各有分工，所以 Transformer 是一套协作的架构，不是一个单独的注意力公式。

### 为什么它特别适合扩大训练规模？

一个重要原因是：**训练时可以并行计算同一序列的多个位置，不必像普通 RNN 那样逐位置递推隐藏状态。** 它也缩短了许多远距离位置之间的信息传递路径。

但必须把两件事分开：

| 情况 | 能不能同时算多个位置？ |
|---|---|
| 训练时，已经有整段训练文本 | 可以，在相应掩码约束下并行计算多个位置 |
| 典型自回归生成时，后续文本还没产生 | 仍逐 token 推进，后面的生成依赖已生成内容 |

对自回归模型来说，**训练时拥有整段文本，不等于每个预测位置都能偷看答案**：因果掩码让一个输入位置只能关注自身和更早位置，用于预测后一个 token。

### 它也不是终点

朴素全注意力要处理成对位置之间的关系：序列长度翻倍，位置配对数量约变成四倍。这说的是配对数量，不等于所有优化实现的实际显存都会精确增长四倍。

同时，“能访问长文本”仍不保证“能可靠用好长文本”。训练数据、目标、优化、计算资源和评估都很重要；有 Transformer 这个架构，也不等于自动拥有一个好用的大模型。

现代大模型的发展还涉及大规模预训练，以及常见的指令微调、偏好优化等后训练。这是另一条“怎么训练”的线，见 [模型训练技术速查](模型训练技术速查.md)，不要与本文的架构演进线混成一件事。

## 7. 对照表与真实时间线

### 不背术语时，可以这样记

| 技术 | 最值得记住的改进 | 仍需注意的边界 |
|---|---|---|
| N-gram | 根据局部搭配次数估计概率 | 上下文有限，组合稀疏 |
| Embedding | 把离散词语变成可学习、可共享规律的表示 | 它是表示技术，不是完整的序列处理方案 |
| RNN | 通过不断更新的状态携带历史 | 长距离学习困难，同一序列有递推依赖 |
| LSTM | 用状态通路和门控控制信息保留、写入、读出 | 不是无限记忆，仍有循环依赖 |
| Seq2Seq + Attention | 生成时按需访问输入各位置，缓解固定摘要的瓶颈 | 仍可能依赖循环网络，读取也可能出错 |
| Transformer | 以注意力进行位置交互，更便于并行训练 | 自回归生成仍有顺序依赖，长序列计算有代价 |

一句大白话串起来：

> **从“查常见搭配”，到“学会词的表示”；从“带着便签往后读”，到“学会保留和更新”；再到“需要时按权重回看”，最后让这种信息交互成为架构主干。**

### 年份不能照着上面的教学顺序排列

| 年份 | 代表性节点 | 不能据此误认为 |
|---|---|---|
| 1997 | LSTM 原始论文发表 | LSTM 是在 2013 年 Word2Vec 之后才出现的 |
| 2003 | Bengio 等人的神经概率语言模型 | 所有神经语言模型都使用循环结构 |
| 2010 | Mikolov 等人的 RNN 语言模型代表工作 | RNN 是 2010 年才被发明的 |
| 2013 | Word2Vec 相关代表工作 | 词嵌入直到 2013 年才出现 |
| 2014 | LSTM Seq2Seq 等序列到序列代表工作 | Seq2Seq 只能用 LSTM 实现 |
| 2014／2015 | Bahdanau 注意力论文：预印本／会议发表 | Attention 是 Transformer 才首次引入的 |
| 2017 | Transformer 论文发表 | 从此所有任务都必须放弃循环网络 |

早期统计语言模型和 RNN 的完整历史没有在这张表中展开。表中是本文涉及的部分代表节点，不做“唯一首创者”的历史认定。

还要纠正一个常见误解：**“统计语言模型 → 神经语言模型”不是“从概率走向不讲概率”。** 神经语言模型同样可以输出条件概率；变化主要在于如何表示输入、如何利用上下文，以及如何学习这套概率分布。

## 8. 自测与答案

### 先试着不看答案回答

1. Trigram 预测下一词时，通常直接保留前几个词作为条件？
2. “Transformer 替代了 Embedding，所以现在不需要词向量。”错在哪里？
3. RNN 与 LSTM 是“两种毫无关系的模型”吗？LSTM 的输出门是否直接选下一词？
4. 给循环网络加入 Attention，是否就自动消除了循环计算？
5. Transformer 能并行训练，是否意味着聊天时一次就生成了全部回答？

### 参考答案

1. **前 2 个**。N-gram 中的 N 包含当前要预测的词。
2. **混淆表示技术与架构**。典型 Transformer 仍使用输入 Embedding，并继续计算上下文表示。
3. **LSTM 是 RNN 家族的一员**。输出门影响隐藏状态，选词概率还要由后续输出层计算。
4. **不是**。注意力负责读取和聚合信息，外围仍可以使用循环结构。
5. **不是**。训练时目标文本已知；典型自回归生成仍逐 token 推进，并受因果约束。

### 一个更有价值的小练习

提交一张自己画的对照图，分别说明：在钥匙故事中，N-gram、普通 RNN、带注意力的模型通过什么路径利用“书包”信息。

**判定标准**：能指出固定窗口、递推状态和按权重访问位置表示的区别；不把示意图当成真实模型内部的中文笔记。

然后把故事改成：

> 小明先把钥匙放进书包，后来又拿出来放进抽屉。……要找钥匙时，他先打开了____

新版本要求处理的是**位置变化**，不是只找一个曾与“钥匙”一起出现的名词。“看得到书包”并不意味着“应该回答书包”。

**迁移检查**：能解释为什么模型既需要保留信息，也需要根据新内容更新信息。若实际测试模型，保存模型版本、完整提示、输出和判定依据，不凭一次答对就断言某种架构必然掌握了规则。
