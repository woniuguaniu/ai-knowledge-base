# 01 模型架构

本模块收录**具体模型的架构创新与技术拆解**——不是"Transformer 是什么"这类通用原理（那在 [00_核心概念](../00_核心概念/README.md)），而是"某个团队在标准架构上改了什么、为什么改、效果如何"。

目前以 DeepSeek 系列为主，是全库**最薄的模块**（2 篇）。

## 笔记列表

| [DeepSeek.md](DeepSeek.md) | DeepSeek 的架构与训练创新，低成本高效率是怎么做到的 |
