# 05 技术基础

本模块收录 AI 项目之外但高频相关的工程基础、部署运维、工具链和产品研发方法。它是目前知识库里跨度最大的模块，阅读时建议按主题分组进入。

## 推荐阅读顺序

1. [Shell与终端基础知识总结.md](Shell与终端基础知识总结.md)：先补命令行基础。
2. [GitHub项目入门/小白入门-GitHub项目部署使用指南.md](GitHub项目入门/小白入门-GitHub项目部署使用指南.md)：从真实项目运行部署开始。

4. [云服务交付模型.md](云服务交付模型.md) → [静态站点生成器与Quartz部署实战.md](静态站点生成器与Quartz部署实战.md) → [CI-CD与GitHub-Actions.md](CI-CD与GitHub-Actions.md)：理解上线和自动化。

## 边缘笔记怎么用

- [swap内存处理技术.md](swap内存处理技术.md)：适合遇到本地模型、Node/Python 构建、Docker 或服务器内存不足时查。它不是 AI 主线，但能解释 OOM、swap、内存压力这类工程故障。
- [逆向API的二分定位方法.md](逆向API的二分定位方法.md)：适合调黑盒接口、Prompt 变量、依赖冲突、慢 SQL 等“找最小影响因素”的问题，本质是通用排错方法论。
- [程序员黑话速查.md](程序员黑话速查.md)：适合遇到术语时用搜索直达，不建议从头线性阅读。

## 维护提示

- 本模块容易膨胀为“大杂烩”。新增笔记前先判断是否需要未来拆成独立模块，例如部署运维、产品研发、硬件环境。
- 超过 800 行的手册优先补目录和章节导航；超过 1500 行时考虑拆子目录。
