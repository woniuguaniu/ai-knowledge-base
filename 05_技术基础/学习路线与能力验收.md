## 1. 先选目标，不要求从头读全库

| 目标 | 起点 | 暂时不必先学 |
|---|---|---|
| 会使用 AI 解决工作问题 | 任务、资料、约束、核验 | Transformer 公式、PPO、GPU 并行 |
| 会开发 AI 应用 | 能运行简单程序；HTTP/JSON、密钥与版本管理 | 自己训练基础模型、复杂多 Agent |
| 理解模型原理 | 向量、矩阵、概率的基本概念 | 追赶所有新品型号与厂商价格 |

## 2. 三条路线

### A. 使用路线：先把一个任务做可靠

| 阶段 | 阅读入口 | 要交出的东西 |
|---|---|---|
| 明确任务 | [AI 对话底层逻辑](../02_提示词工程/01_AI对话的底层逻辑.md)、[第一个提示词](../02_提示词工程/02_写好第一个提示词.md) | 一份包含目标、输入、约束、验收条件的任务说明 |
| 控制输入与输出 | [用示例教会 AI](../02_提示词工程/03_用示例教会AI.md) | 正常、缺信息和冲突资料三类输入及输出记录 |
| 核验而非相信 | [优化与评估](../02_提示词工程/09_系统化优化与评估.md)、[典型失败模式](../06_Agent工程/LLM典型失败模式.md) | 逐条核对事实与出处，指出至少一个看似合理的错误 |
| 完成小项目 | [工作效率场景](../02_提示词工程/06_工作效率场景.md)、[练习题集](../02_提示词工程/练习题集.md) | 可重复使用的任务模板、前后对照结果及适用边界 |

评测不是“专家阶段才用”的知识。第一次使用 AI 就应核验，只是初期可以人工核对。

### B. 开发路线：先单模型闭环，再增加复杂性

| 阶段 | 阅读入口 | 要交出的东西 |

| API 最小应用 | [LLM 接口规范实战](../03_应用实践/LLM接口规范实战.md) | 密钥不入库；能处理失败、超时；记录模型和请求配置 |

### C. 原理路线：从能计算的机制到能解释的边界

1. **Token 与表示**：读 [上下文与 Token](../00_核心概念/上下文窗口与Token计费.md)、[文本理解](../00_核心概念/大模型如何理解文本.md)。区分 tokenizer、输入 embedding、上下文表示和整段文本 embedding。
2. **注意力与架构**：读 [注意力机制](../00_核心概念/注意力机制.md)、[Transformer](../00_核心概念/Transformer.md)。手算一次归一化权重，解释为什么因果掩码禁止看未来。
3. **训练与推理**：读 [训练技术速查](../00_核心概念/模型训练技术速查.md)、[Dense 与 MoE](../00_核心概念/Dense与MoE架构对比.md)。区分训练目标、推理过程、总参数与激活参数。
4. **有问题再深入**：需要理解位置泛化再学 RoPE；研究偏好优化再学 PPO/DPO 等。待补专文见 [路线图](../ROADMAP.md)，不把链接覆盖当成知识已经讲全。

## 3. 贯穿项目：可核验的资料问答助手

选一组自己有权使用、无敏感信息的小型文档；不使用诊疗、交易等高风险任务作为初学者上线实验。

| 层级 | 新能力 | 验收产物与判定 |
|---|---|---|
| L1 提示词版 | 只依据提供的材料回答 | 问题、材料、回答、逐条出处；资料缺失时明确不足，不编造 |
| L2 检索版 | 自动找到相关材料 | 保存检索片段；能区分“没检索到”和“检索到却答错” |
| L3 工具版 | 使用受控的只读查询工具 | 参数与权限测试；材料中的恶意指令不能获得额外工具权限 |
| L4 工程版 | 可观测、可停止、可恢复 | 超时/限流/工具失败测试、预算上限、trace 与回滚记录 |

建议教学起步使用 20–30 个问题，包含正常、缺信息、相互矛盾、恶意指令四类；另留未用于调提示词的问题用于验收。**这个数量是练习规模，不是统计可靠性或生产上线标准。** 正式项目需按风险、任务分布与置信区间设计样本量。

测试前约定目标，保存失败而不是只展示最佳输出。出现未授权操作或伪造引用等严重失败时，先修边界，不用整体高分掩盖。自动测试发现“本次零越权”也不证明以后绝对安全。

## 4. 验收与复习

个人能力单独记录，不给自己预填“已掌握”：

| 状态 | 判定方法 |
|---|---|
| 未学 | 尚未完成阅读或实验 |
| 能解释 | 不看原文讲清概念、一个例子和一个反例 |
| 能照做 | 根据教程复现，保留环境和结果 |
| 能独立完成 | 换一组输入或新任务，不逐步抄教程仍能完成 |
| 能诊断失败 | 人为制造故障，定位原因，修复并做回归检查 |

记录字段：主题、当前状态、证据路径、失败案例、下一步。教程已有示例不算自己的实测。

复习建议：学完立即尝试闭卷解释；隔几天换输入复做；隔一两周用新场景检查迁移。间隔按遗忘和难度调整，不以固定天数承诺掌握。
