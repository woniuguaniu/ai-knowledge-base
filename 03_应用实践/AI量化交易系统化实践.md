## 1. 为什么学AI量化

### 1.1 行业数据（2026年4月）

| 指标 | 数据 | 增长 |
|------|------|------|
| 存量私募管理人 | 18,792人 | - |
| 证券私募管理人 | 7,379人 | - |
| 存量私募基金 | 142,078只 | - |
| 存量私募规模 | 23.46万亿 | 六年增长72.35% |
| 百亿级私募数量 | 71家（2025-06） | 从28家（2022）增长2倍+ |

### 1.2 核心观点

**普通人不需要复制机构规模，而要学习机构的研究流程**：

```
数据 → 规则 → 验证 → 风控 → 复盘
```

### 1.3 为什么CTA适合作为入门案例？

CTA（商品交易顾问）策略天然规则化，有四个优势：

| 维度 | 核心问题 | 为什么适合入门 |
|------|---------|--------------|
| **01 趋势** | 如何判断大方向？ | 上涨、下跌、震荡等形态明确固定且易于判断 |
| **02 波动** | 如何控制波动幅度？ | 风险控制、风险敞口等，掌握资金与风险管理 |
| **03 仓位** | 如何控制资金比例？ | 避免因资金比例不足导致亏损，验证资金管理能力 |
| **04 回测** | 如何验证回测？ | 持续复盘与优化，用适当可测量的指标评估系统 |

**结论**：零基础从规则开始，可验证、可量化的验证流程入门。

## 3. AI量化研究链路（8步）

从研究课题走向可验证、可执行、可迭代的量化策略。

```
问题 → 数据 → 因子 → 信号 → 策略 → 回测 → 执行 → 评估
  ↓      ↓      ↓      ↓      ↓      ↓      ↓      ↓
发现   收集   构建   生成   设计   验证   实盘   效果
研究   基础   因子   信号   交易   历史   执行   评估
课题   数据   体系   序列   规则   表现   交易   优化
```

**💡 核心观点**：任何一步出现短板，都将影响整条链路的最终表现。

## 4. 单点学习的三个失败场景

### 场景1：只学模型

- **问题**：模型虽能跑，但不知道标签、特征、样本怎么做才对应
- **结果**：🧠 模型会跑 + 策略跑不通

### 场景2：只学代码

- **问题**：代码能跑，但不知道策略框架设计、数据分析到的验证逻辑
- **结果**：</> 代码能跑 + 研究不可复盘

### 场景3：只学因子

- **问题**：因子能生成，但不知道策略接驳逻辑、筛选标准，频繁过拟合
- **结果**：📊 因子越多 + 能力越弱

**⭐ 结论**：单点能力越多，不代表系统能力越强。

### 单点学习 vs 系统化学习对比

| 单点学习 | → | 系统化学习 |
|---------|---|-----------|
| 学一个框架 | → | 建一条研究链 |
| 抄一段代码 | → | 理解策略从哪里来 |
| 调几个参数 | → | 知道如何验证结果 |
| 做几个因子 | → | 建立因子生产体系 |
| 看一条回测曲线 | → | 判断结果是否可信 |
| 依赖AI生成代码 | → | 学会和AI协作研发 |

## 5. 系统化学习的五层能力地图

从底到顶，逐步搭建工具、覆盖闭环、最后进入工程和评估。

```
        ╔═══════════════════════════════════╗
        ║  05 | 科学评估                    ║
        ║  看懂杂性、过拟合检测和真伪识别   ║
        ╠═══════════════════════════════════╣
        ║  04 | 因子工程                    ║
        ║  批量生成、管理和优质因子         ║
        ╠═══════════════════════════════════╣
        ║  03 | 策略闭环                    ║
        ║  从想法到信号到规则、风控、部署   ║
        ╠═══════════════════════════════════╣
        ║  02 | AI研发提效                  ║
        ║  用AI优化策略周期、调试、复盘效率 ║
        ╠═══════════════════════════════════╣
        ║  01 | 基础底座                    ║
        ║  看懂数据、因子、信号、回测、执行 ║
        ╚═══════════════════════════════════╝
```

### 5.1 第一层：基础底座

**六大模块**：
- **数据**：研究原材料
- **因子**：市场规律表达
- **信号**：交易切入入口
- **策略/模型**：决策链路
- **回测**：结果验证
- **执行**：真实的盘

**核心问题**（6个维度）：
1. 数据是什么？研究原材料，如何获取与清洗
2. 因子是什么？市场规律的表达式，如何设计与构建
3. 信号怎么生成？从因子预测信号序列，如何做基准与过滤
4. 策略该如何设计？策略框架如何设计，如何控制波动性
5. 回测怎么做？验证策略有效性，如何科学评估
6. 执行有什么条件？策略交易到实际执行，如何控制偏差

**能力底座**（4个支撑）：
- 🏗️ AI基础框架：Pandas, Numpy打地基快速掌握
- 🔬 AI框架：通过项目式开发学习，方法先于工具
- ⚙️ 描框架拓展：避免用学习的陷阱进入规则
- 🛠️ 因子工具：现学现用定制预测的策略优化

### 5.2 第二层：AI研发提效

大模型不是替代思考，而是提高策略迭代的效率。

**五大AI应用场景**：

1. **需求拆解**：把抽象想法拆解成任务序列（数据、因子、信号、回测等）
2. **代码草稿**：快速生成代码框架（读取、计算、回测、规避常见坑）
3. **调试重构**：定位错误、修复调整（运行报错、排错陷阱、补充易错项）
4. **研报转策略**：探究迹、文本转因子的深度分析（可执行函数的策略思路）
5. **复盘报告**：自动提取关键指标，规避错误和风险（输出需要的周知度报告）

**💡 核心观点**：
- 有系统的人用AI，会得到更高效率
- 没有系统的人用AI，只会得到更多碎片

### 5.3 第三层：策略闭环

**完整的六步流程**：

```
目标设定 → 标签设计 → 模型训练 → 回测验证 → 风险设计 → 部署复盘
```

**策略闭环要解决什么？**

- **🎯 需明目标**：规做什么、交做什么、用什么接口、如何评价
- **📈 规现优化**：如何分组、目标序数、文本做规、超参搜索
- **🏆 成果系统**：止跌止盈、仓位管理、动态策略、优化仓位比
- **🔄 自定化规则**：规验判断、做生成链、Cutoff 市策、指标与复盘
- **🔄 部署复盘**：极致迭代、效果定盘、部署复规、规做优化

**⭐ 策略闭环的重点**：不是单个环节多厉害，而是从AI研究到执行能不能整体串起来。

### 5.4 第四层：因子工程

从手工试错痛苦，升级为可批量生成、可追踪、可管理的因子生产体系。

**对比：单点做因子 vs 系统化因子工程**

| 单点做因子 | 系统化因子工程 |
|-----------|--------------|
| 拼接 → 参数 → 过滤 → 检讨/废弃 | 定义 → 批子 → 组量 → 推量 → 筛选 |
| ⚠️ 单手试、费时间、难复现 | ✅ 可追溯、可扩展、可复盘入体系 |

**💡 核心观点**：因子工程不是做一个因子，而是建立可持续生产因子的能力。

### 5.5 第五层：科学评估

结果多了以后，关键是能不能相信。

**核心问题**：验证和回归升级延续感，在精力回到不亏损"看信号结果"而已，而是"提醒您不到规"。

**六大评估维度**：

1. **🔍 需要回过的关键问题**：回测是什么
2. **🛡️ 是否稳健性？**：超线后规及期策略盘
3. **📊 是否过拟？**：是否市场发生现空
4. **⚖️ 还抛策可平？**：策略检盘结发现现空间
5. **📈 收益比如何？**：仓位用策策略过验
6. **🎲 样本性合适？**：收规仓对指不能验期问

**💡 核心观点**：回测曲线只是结果之一，不是验证标准。科学评估让你读懂"可复现的真能力"。

## 6. AI在量化中的五大应用场景

### 6.1 需求拆解

**场景**：把抽象想法拆解成任务序列
- 输入：用户的模糊想法（"我想做一个动量策略"）
- 输出：数据、因子、信号、回测等的具体任务序列

### 6.2 代码草稿

**场景**：快速生成代码框架
- 输入：策略描述
- 输出：读取、计算、回测、规避常见坑的代码框架

### 6.3 调试重构

**场景**：定位错误、修复调整
- 输入：报错信息、代码片段
- 输出：运行报错、排错陷阱、补充易错项，一步到位

### 6.4 研报转策略

**场景**：探究迹、文本转因子的深度分析
- 输入：研报PDF、论文
- 输出：可执行函数的策略思路

### 6.5 复盘报告

**场景**：自动提取关键指标
- 输入：回测结果数据
- 输出：规避错误和风险，输出需要的周知度报告

## 7. AI的正确用法 vs 常见大坑

### 7.1 AI可以做到（✅）

- **🖥️ 增代码**：代码框架比、界外序列
- **🗺️ 解释规则**：解释市场的规则、策略逻辑
- **🎯 生成框架**：拼接的框架、模板路径
- **📊 整理报告**：功能输出统、文献梳理
- **🔄 研战略整面的策略**：从阅读论文到生成策略

### 7.2 AI会踩的大坑（❌）

| 大坑 | 后果 |
|------|------|
| **❌ 错误数据口径** | 导致指策略全面偏差 |
| **❌ 错误选择模型** | 方法论及、模型选择错误 |
| **❌ 未来函数** | 看传精验、实效无实效 |
| **❌ 过拟合** | 抓非拟合、样本外差 |
| **❌ 不可解释的黑箱模型** | 无法战略、无法解释 |

### 7.3 核心对比

**✅ AI的正确做法**：辅助做 → 验证拆解 → 规范对齐 → 策略实施
- **内容拆解**：规划性拆解、策略分解、数据梳理
- **生成代码**：智能生成码、主逻辑结构、输错拦截分析
- **规验证**：无监督规验证跟复盘验证

**❌ AI不该做进而错**：直接预测 → 研不对错比 → 研究无效链
- **内容强搜**：看单张流片、研不好核比、相标落分析
- **规低纲**：规范分泛、好不好部架、相错相成

**⭐ 没有研究框架的，AI只是更快给你产生碎片；有研究链路的，AI才是真提效助产工具。**

## 8. 三阶段学习路径

### 阶段1：研究入口

**学习内容**：
- AI量化思路解析什么
- 策略为什么可复现
- Python结合CTA案例
- AI量化功能研究入口

**交付成果**：真实策略 + 可迭代框架 + AI辅助研究入口

### 阶段2：数据到因子

**学习内容**：
- 数据整理与标准化
- 因子表达框架
- 因子评价体系
- 因子筛选盘

**交付成果**：可迭代、可复盘、可查代因子产品

### 阶段3：策略到执行

**学习内容**：
- 信号与规则闭环
- 量化小组合报盘
- 策略构建完整体系
- 执行与验证流程

**交付成果**：因子级入验证、回测、策略和策略可实版规

**💡 先理解边界，再让AI进入可验证、可交付的研究流程**
