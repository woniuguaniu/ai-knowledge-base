# 04 探索日志

本模块归档**一次性的探索过程**：某天围绕某个主题的完整问答、踩坑、复盘。它和其他模块的区别是——

- **其他模块**存的是**沉淀后的结论**，会被反复修订，追求"随时能查"
- **本模块**存的是**当时的过程**，写完基本���改，追求"能还原当时怎么想的"

所以这里的笔记允许保留弯路、错误判断和中途推翻的结论——那正是它的价值。

## 命名与格式规范

- 文件名：`YYYY-MM-DD_主题.md`（日期在前，便于按时间排序）
- 新建时**复制** [_templates/探索记录模板.md](../_templates/探索记录模板.md)，保留「基本信息」段
- 一次探索一个文件，不要把多天的内容塞进一篇

## 探索日志与正式笔记的关系

探索日志是**原料**，正式笔记是**成品**。典型流转：

```
一次探索（04_探索日志/YYYY-MM-DD_X.md）
    ↓ 沉淀出可复用的结论
正式笔记（00~07 对应模块/X.md）
    ↓ 日志保留反向链接
"这篇笔记的由来见 04_探索日志/…"
```

已经形成成品的例子：[2026-05-19 表演性完成失败模式](2026-05-19_LLM表演性完成失败模式.md) → [LLM典型失败模式](../06_Agent工程/LLM典型失败模式.md)。

## 维护提示

- 日志**不追求时效性**——它记录的是"那天的认知"，即使结论后来被推翻也不要删改，而是在正式笔记里更新，日志里加一句指向。
- 如果一篇日志里的结论已经完全沉淀进正式笔记，可在日志顶部加一行指路，但保留原文。
