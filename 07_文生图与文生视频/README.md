# 07 文生图与文生视频

本模块收录**视觉生成方向**的内容：文生图（Text-to-Image）、文生视频（Text-to-Video）的提示词写法、模型选型与工作流。

这是**新开的模块**（2026-08），目前内容还很少。它从 [02_提示词工程](../02_提示词工程/README.md) 独立出来的原因是：**图像提示词和文本提示词是两套不同的技能**——文本提示词讲的是任务拆解、角色设定、思维链；图像提示词讲的是要素堆叠、权重、负向词、采样参数，两者几乎不共享方法论。

## 待补方向

本模块还很薄，以下是明确的空缺（**已被现有笔记覆盖的不再列入**——负向提示词见该笔记 § 6.2、文生视频基础见 § 7）：

- 主流文生图模型的横向对比（Stable Diffusion / Flux / Midjourney / gpt-image 系列）
- 负向提示词的**对症手册**：常见画面缺陷（手崩、多指、脸糊、构图失衡）分别该写什么
- 采样器、步数、CFG scale 等参数的实际影响
- ControlNet / LoRA 等可控生成手段
- **独立的文生视频专题**：现有内容只是文生图笔记的延伸小节，缺模型横评（Sora / Kling / Runway 等）与图生视频、首尾帧工作流
- 生成后的必要后处理——分辨率提升与超分工作流

## 维护提示

- 视觉生成领域**迭代极快**，模型名称、参数默认值、平台限制半年就可能失效——本模块笔记务必标注资料日期和对应的模型版本。
- 涉及具体平台的输出规格（单张像素上限、支持的宽高比）时，写清是哪个平台哪个时间点的规格。
